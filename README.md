# Kurashi Akari (暮らし灯)

> A premium Japanese smart home technology and lifestyle brand website built with Next.js.

![Kurashi Akari Hero Preview](/images/hero-interior.png)

**Kurashi Akari (暮らし灯)** is a modern, responsive website concept for a fictional Japanese smart home technology company. It blends traditional Japanese minimalism with cutting-edge smart home automation concepts. 

The website is built with a focus on high-performance, elegant micro-animations, and a highly polished UI.

## Features

- **Cinematic Hero Section**: Immersive hero section with procedural light particle animations and stunning photorealistic background.
- **Interactive SVG Configurator**: An interactive "Smart Home Configurator" built entirely with CSS variables, SVGs, and React state. Users can customize room lighting, climate, security, and lifestyle scenes.
- **Dynamic Scroll Animations**: Custom scroll reveal hooks (`IntersectionObserver`) combined with Tailwind CSS keyframes for smooth entrance animations across all pages.
- **Responsive Design**: Carefully crafted fluid layouts and typography (Noto Sans JP / Noto Serif JP) that scale beautifully from mobile to desktop.
- **Static Site Generation (SSG)**: fully optimized and statically generated for rapid loading and SEO.

## Tech Stack

- **Framework**: [Next.js 16.3](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom configuration for Japanese brand colors (Charcoal, Warm White, Paper, Muted Green, Amber, Accent Blue)
- **Icons & Graphics**: Pure CSS and custom SVG components (No external icon libraries).

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
